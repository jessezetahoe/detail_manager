Detail Manager: How To

Draft for the people using it now. It will be revised for the company release.

Starting and closing

  1. Double-click the Detail Manager shortcut on your desktop. A black window opens, then Detail Manager opens in your web browser.
  2. Keep the black window open while you use Detail Manager (you can minimize it). Closing it stops the program.
  3. Only one Detail Manager can run at a time. If the black window says the port is already in use, an older one is still open: close that black window first.
Searching works straight away; there is no need to refresh every day. See When to Refresh Index.

Finding a detail

Search box (top)

  • Type a few words: king stud, retaining, moment frame. Partial words work (shea finds shear).
  • Abbreviations work both ways: TJI and I-Joist, FLR and floor, 3PLY and triple.
  • Results show the best matches first, up to 80. Add a word to narrow them down.

Left panel

  • Categories narrow the results to one kind of detail (Foundation, Floor to Beam, Roof ...). Search then works inside that category. All Details clears it.
  • Library | Non-Library | Both (top of the panel, shown once job details are set up): which details to search. See Non-Library Details.
  • Source files (advanced): pick one master LayOut file. Rarely needed.

Cards and the detail window

  • Each card shows the picture, the title drawn on the detail, and the SketchUp scene in plain words.
  • Click the picture (or Preview) to open the detail window: a larger picture, the notes on the detail, every scene and SketchUp path, and the buttons.
  • Thumbnail slider (top right): bigger or smaller cards.

Getting a detail into your project

  1. Click Open Detail on the card (or in the detail window). LayOut opens a small temporary file that holds only that detail, with all its views, labels and callouts.
  2. In that temporary file press Ctrl+A (select all), then Ctrl+C (copy).
  3. Close the temporary file. If LayOut asks to save it, choose Don't Save: it is only a copy.
  4. Go to your project and press Ctrl+V (paste). Move it into place.
Copy and paste is the right way: LayOut then keeps one shared SketchUp reference when several details come from the same model, exactly as when copying from the masters by hand. The detail stays grouped.
  • Master opens the full master LayOut file (look only; do not save changes to masters from here).
  • Open in SketchUp (detail window) opens the SketchUp model the detail comes from, already at the detail's scene. A detail with several views has an Open in SketchUp button beside each scene. Switching to the scene needs the Zachary Engineering Toolkit in SketchUp; without it the model opens as it was last saved. Library models are for looking: do not save changes to them.
  • Temporary files are deleted automatically after 24 hours. To delete them now: Library and admin tools > Clean Staging Files (close them in LayOut first).

Several details at once (cart)

  1. Click + Cart on each detail you need (it turns into In Cart; click again to take it out). The cart bar appears at the bottom.
  2. Click Open All in LayOut. Each detail opens as its own temporary file, and the cart empties.
  3. In each file: Ctrl+A, Ctrl+C, close it, Ctrl+V in your project.
  • The cart is kept when Detail Manager is closed. Clear Cart empties it; the × on a picture removes one detail.
  • Up to 25 details at a time. If one cannot be opened, it stays in the cart and the reason is shown (also in Diagnostics).

Non-Library Details (jobs)

Details drawn for jobs that are not (yet) in the library. They are searched separately and always marked with an orange NON-LIBRARY · JOB badge.

Setting it up (once per computer)

  1. Open Library and admin tools (left panel) > Choose Non-Library Details Folder, and pick the folder where job-specific details are kept.
  2. Detail Manager reads the folder straight away (a Refresh Index starts by itself). The Library | Non-Library | Both switch then appears.

Adding a job

  • Put the job's LayOut detail file(s) in that folder: loose, or in the job's own folder. Start the file name or the folder name with the job number (1875 S2.1-S2.4.layout or 1875\...).
  • Click Refresh Index.
  • To leave a job out, take its file out of the folder and refresh. Backup files (Backup of ...) are always ignored.
  • Details parked off the sheet (beside the page) and SketchUp views that are not inside a detail group are left out. Diagnostics lists how many per file.

Reading the cards

  • In 12 jobs: exactly the same detail occurs in that many jobs. It is shown once; the detail window lists every job with its own Open Detail button.
  • Most used in jobs (next to the result count): lists the most used job details first: good candidates for the library.
  • Same as Library: ...: a job copy of a library detail. In Both these are hidden and the library card says Also used in N jobs.
  • Custom model / Old library model: where the detail's SketchUp model lives.

When to Refresh Index

Refresh Index (top right) reads the master files again. It only reads; it never changes them. Masters that did not change are skipped, so a normal refresh takes seconds.

Refresh after ...Why
A library master was added, changed or removedNew and changed details appear; removed ones disappear
Job files were added to (or taken out of) the Non-Library Details folderSame, for job details
Detail Manager was updatedThe first refresh after an update can take about 2 minutes (it reads everything once). Pictures are kept
abbreviations.json was editedSearch words come from it; the next refresh reads everything once
  • A changed master loses its full thumbnails until the next render (its cards show the plain SketchUp view meanwhile). See Full thumbnails.
  • If the Z: drive (or the job folder) cannot be reached, nothing is removed: the refresh stops and says so (and Diagnostics shows it).

Full thumbnails (admin task)

Full thumbnails show the whole detail with labels and callouts. Until a master has them, its cards show the plain SketchUp view (badge Viewport Cache). Only new and changed masters (and new job files) are rendered, so after the first time a render is quick. The line above the buttons says how many masters need rendering. Do it after a Refresh Index that found new or changed files.

  1. In Detail Manager: Library and admin tools > 1. Prepare Render Queue. It queues only the masters that need it (or says there is nothing to render). If files were added or changed since the last Refresh Index, it says so: refresh first, then prepare again. The layer to hide, normally GUIDES, is listed above it.
  2. In SketchUp: Extensions > Zachary Engineering Toolkit > Detail Manager > Admin > Render Thumbnails... and confirm. SketchUp opens each queued master read-only, makes a PDF of it and never saves it; the status bar shows the progress and a message says when it is done.
    Without the toolkit: Extensions > Developer > Ruby Console, then type load 'C:/sketchup_dev/detail_manager_release/thumbnail_worker.rb' and press Enter.
  3. Back in Detail Manager: 3. Process Rendered Thumbnails.
  • To redo every master (rarely needed), tick Re-render everything before step 1. Changing the hidden layer list does this by itself.
  • Step 3 skips masters it has already turned into thumbnails.
Step 3 needs PyMuPDF on the computer. If it says it is missing, run py -m pip install pymupdf in Command Prompt once.

Editing names and abbreviations

Two small files in the program folder (C:\sketchup_dev\detail_manager_release), editable with Notepad:

  • categories.json: the categories in the left panel and which scrapbook numbers (01), (02) ... belong to each. Save, then reload the Detail Manager page.
  • abbreviations.json: what shorthand means ("TJI": "I-Joist"). Only add words the detail really has (no brackets or "e.g."). Save, then Refresh Index.

A mistake in either file never stops the program: it uses its built-in list and says so in Diagnostics. Note: a new program version replaces these files, so tell whoever maintains Detail Manager about changes you want kept.

Diagnostics and problems

Diagnostics (bottom of the left panel) shows a red number when something needs a look: master files that could not be read, the Z: drive or job folder not reachable, what was left out (views not inside a detail group, details parked off the sheet), and the last thumbnail render. Open Log Folder opens the log, which helps when reporting a problem. The version number is at the top left (and in Diagnostics): mention it when reporting a problem.

What Detail Manager never does

  • It never saves or changes the master LayOut or SketchUp files, and never changes the SketchUp paths inside them.
  • It never writes anything into the library or job folders. Its own data (index, pictures, temporary files, log, cart) is kept on this computer in %LOCALAPPDATA%\ZE Detail Manager.
  • Once a detail is pasted into a project, Detail Manager does not manage it: later library changes do not change your project.
